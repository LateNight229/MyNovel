## 🔄 User Journey

```
User visits novel site
        ↓
Extension icon visible in toolbar
        ↓
        Click extension icon
        ↓
    ┌───────────────────────┐
    │  Popup shows:         │
    │  - Toggle button      │
    │  - Quick settings     │
    │  - Library buttons    │
    └───────────────────────┘
        ↓
    Click "Enable Reader Mode"
        ↓
    ┌───────────────────────┐
    │  Clean reader shows:  │
    │  - Article only       │
    │  - No ads             │
    │  - Settings control   │
    └───────────────────────┘
        ↓
    Choose: Save / Customize / Export
        ↓
    ┌──────────────────────┐ ┌─────────────────────┐
    │ Save to Library      │ │ Customize Reading   │
    │ - Add to offline db  │ │ - Font size         │
    │ - View stats         │ │ - Colors            │
    │ - Export later       │ │ - Theme             │
    └──────────────────────┘ └─────────────────────┘
        ↓                           ↓
    Return to Library         Continue Reading
        ↓                           ↓
    Manage Collection         Enjoy Reading
        ↓
    Export to EPUB for e-readers
```

## 📊 Data Flow

```
Novel Page
    ↓
Content Detector analyzes DOM
    ↓
├─→ Finds main article
├─→ Removes ads
├─→ Extracts title
└─→ Detects chapters
    ↓
Content Script
    ├─→ Replaces page with reader UI
    ├─→ Applies saved settings
    └─→ Listens for user actions
    ↓
User Interactions
    ├─→ Settings changed
    │   ├─→ StorageManager.saveSetting()
    │   └─→ Content updated immediately
    │
    ├─→ Save chapter clicked
    │   ├─→ Extract content + metadata
    │   ├─→ StorageManager.saveChapter()
    │   └─→ Show confirmation
    │
    └─→ Export EPUB clicked
        ├─→ Query IndexedDB for chapters
        ├─→ EPUBBuilder.buildEPUB()
        └─→ Download .epub file
```

## 💾 Storage Structure

```
IndexedDB: NovelReaderDB
│
├─ series (Object Store)
│  └─ {id, title, author, url, description, cover}
│
├─ chapters (Object Store)
│  ├─ Index: seriesId
│  ├─ Index: url (unique)
│  └─ {id, seriesId, title, url, content, html, wordCount, addedDate}
│
├─ settings (Object Store)
│  └─ {key: value, key: value, ...}
│     (fontSize, fontFamily, lineHeight, theme, etc.)
│
└─ crawlQueue (Object Store)
   ├─ Index: status
   └─ {id, seriesId, url, title, status: "pending|in_progress|completed"}
```
